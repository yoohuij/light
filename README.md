# light

고죠봇에서 DM 공지, 회의, 반응 확인, 관리자 및 예외 관리만 분리한 독립 봇입니다. 기존 봇의 토큰·관리자·예외·후원 기록을 복사하지 않습니다.

## 실행

Python 3.12 이상을 사용하세요. 시작 파일은 `bot.py`입니다.

```powershell
cd "C:\Users\유희준\Documents\Codex\2026-09-19\new-chat\light"
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py
```

최초 설치 후에는 마지막 줄로 실행합니다. 호스팅에서도 requirements.txt를 설치하고 `python bot.py`로 실행합니다.

로컬 `.env` 또는 호스팅 환경 변수의 `DISCORD_TOKEN`에 새 봇 토큰을 넣으세요. GitHub에는 `.env.example`만 포함합니다. `.env`가 없다면 예제 파일을 복사해 만드세요. 환경 변수에 이미 토큰이 있으면 그 값이 우선됩니다.

Discord 개발자 설정에서 Server Members Intent를 켜고 봇을 서버에 초대하세요. 기본적으로 채널 보기, 이전 메시지 보기, 메시지 보내기, 링크 임베드 권한이 필요합니다. 회의 공지에는 everyone 멘션 권한이 필요하며, 회의 채팅 교체 및 퇴장에는 채널 관리·역할 관리·메시지 관리·멤버 이동과 스테이지 관리에 필요한 권한이 필요합니다.

## 명령어

- DM: `/공지` — 내용 입력창, 예외를 제외한 서버 구성원에게 개별 전송. 제목은 `[light 공지]`입니다.
- 회의 설정: `/회의방등록`, `/로그방등록`, `/공지방등록`, `/사유방등록`, `/회의채팅방지정`
- 회의 운영: `/회의공지`, `/회의 시작`, `/회의 종료`
- 불참 사유: `/불참자`, `/불참자명단`, `/사유확인`, `/사유초기화`, 공지의 사유 신청 및 수락·거절 버튼
- 참석 확인: `/잠수확인`, `/미참여자확인`, `/미참여반응자`
- 관리자: `/관리자 부여`, `/관리자 해제`, `/관리자 목록`
- 예외: `/예외설정`, `/예외설정역할`, `/예외목록`

관리자 지정과 예외 관리는 봇 소유자만 가능합니다. 회의 채널 지정은 봇 또는 서버 소유자만 가능합니다. 공지·회의 운영과 사유 처리는 소유자와 등록 관리자가 사용할 수 있습니다. `/미참여반응자`도 소유자와 등록 관리자가 사용할 수 있으며 결과는 본인만 봅니다.

관리자와 개인 예외는 이 봇 전체에 공통 적용됩니다. 역할 예외와 회의 설정은 서버별입니다. 예외자는 불참자명단에 자동 포함되고 사유 초기화 후에도 유지됩니다.

`/잠수확인`은 현재 등록된 회의방 안의 사람 중 예외·불참자를 제외하고, 지정 메시지에 반응하지 않은 사람을 표시합니다. 일반·슈퍼 반응을 합산합니다. 메시지 ID는 봇이 읽을 수 있는 같은 서버의 다른 채널에서도 찾습니다.

회의 종료 시 지정된 회의채팅방을 새 채널로 교체해 이전 채팅을 삭제하고 잠그며, 회의 음성방 참여자를 퇴장시킵니다. 삭제한 채팅은 복구되지 않습니다. 스테이지 세션도 종료합니다. 기존 회의 채팅과 별개로 전용 채널을 지정하세요.

## 저장 및 운영

첫 실행 시 봇 폴더에 `attendance.sqlite3`가 생성됩니다. 재시작 시 유지되지만 다른 호스팅으로 이동하면 이 파일을 별도로 옮겨야 합니다. 같은 토큰으로 동시에 여러 곳에서 실행하지 마세요.

Discord의 전송 제한 또는 사용자의 DM 차단으로 메시지가 실패할 수 있습니다. 요청 제한 오류가 발생하면 연결을 중단하며 장시간 보호대기를 저장하지 않습니다. 명령어 동기화는 내용이 바뀐 경우에만 수행합니다.

후원·닉네임 변경·역할 카테고리·경고·테러 방지·업자 기능은 포함하지 않습니다.
